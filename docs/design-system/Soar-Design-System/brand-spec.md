# SOAR Brand Specification

SOAR uses a light, compact campus-product language: grounded navy structure, optimistic gold actions, clear typographic grouping, and bright accents reserved for navigation and status.

## Core OKLCH tokens

```css
:root {
  --bg: oklch(98.22% 0.0041 271.4);
  --surface: oklch(100% 0 0);
  --fg: oklch(21.13% 0.0391 282.5);
  --muted: oklch(49.88% 0.0309 273.6);
  --border: oklch(91.28% 0.0113 269.5);
  --accent: oklch(81.49% 0.1663 78.4);
}
```

## Typography

- Display: `Avenir Next`, `Segoe UI Variable Display`, `Segoe UI`, sans-serif
- Body: `Segoe UI Variable Text`, `Segoe UI`, Arial, sans-serif
- Mono: `IBM Plex Mono`, `Cascadia Code`, Consolas, monospace

## Logo direction

- Selected concept: an open S-shaped route with a detached upward arrow.
- Primary variant: **Open Path**; use **Bold Path** when strokes would disappear below 24px.
- Reuse the mark in the app header, organization navigation, app icon, favicon, and compact phone lockup.

## Visual rules

1. Use navy for hierarchy and gold for the one primary action in a view.
2. Keep cards white and minimally rounded; use spacing and surface contrast before borders or shadows.
3. Treat officers as students with scoped organization permissions, not a separate persona.
4. Use blue for informational navigation; reserve orange accents for attention and progress states.
5. Use 4-8px gaps for related title-description pairs, 12-16px between controls, and larger gaps only between separate sections.
